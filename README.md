# 🚀 Prodigy InfoTech Web Development Internship - Task 03

## 📌 Project Overview
This repository contains **Task 03** of the Web Development Internship at **Prodigy InfoTech**. The objective of this task was to build a fully interactive, feature-rich **Tic-Tac-Toe Game** featuring player-versus-AI bot mechanics, real-time win/draw detection, and dynamic animated winning strike-through lines.

---

## ✨ Key Features & Functionality
* **Smart AI Opponent:** Play as Player (X) against an intelligent automated bot (O) that calculates strategic block and win moves.
* **Dynamic Strike-Through Animation:** Automatically draws a glowing neon line across the winning row, column, or diagonal when a victory is secured.
* **Visual Cell Highlighting:** Highlights winning tiles with a smooth pulse effect and announces the winner or draw in real time.
* **Sleek Dark-Tech Aesthetic:** Styled with custom neon accents (Cyan for X, Purple for O, Emerald Green for winning indicators) using modern CSS glassmorphism.

---

## 🛠️ Technologies Used
* **HTML5:** For structured game board layout and UI components.
* **CSS3:** For styling, grid layouts, transitions, and dynamic absolute-positioned winning lines.
* **JavaScript (ES6+):** For game state management, turn alternation, AI heuristic decision-making, and DOM manipulation.
* **FontAwesome:** For interface icons.
* **Google Fonts:** For modern typography (`Plus Jakarta Sans`).
